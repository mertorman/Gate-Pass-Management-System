<h3 align="left">Application Purpose:</h3>

<p align="left">In this study, parking lot management was carried out with the help of a mobile application-based parking management system. This application is a software solution that enables effective and efficient management of the parking lot. The application, which has the functions of opening and closing the parking lot gate via the mobile application, is also used to regulate school entrances and exits, and provides control of the people passing by. The system can determine the access of each user to this gate and the access authorizations can be easily monitored by the administrator. In this way, the security of the parking lot is increased and unauthorized access is prevented. At the same time, the system keeps a record of those who enter and exit, thus, parking lot management and security are realized. The time for users to enter and exit the parking lot has increased by 50%.
</p>
